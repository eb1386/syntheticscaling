# Abstract (draft; ≤ 250 words; every bracketed value is a placeholder to be read from results/index.parquet)

A lab that holds a small pretrained language model and a fixed generation budget must choose which teacher writes its synthetic training data. Prior answers come from neighbouring regimes (logit distillation, instruction tuning of 7B-class students, web rephrasing), where generator size stops helping between roughly 1B and 8B parameters. We measure the effect directly for sequence-level synthetic data in the annealing phase of small students. Five students of 25M to 1B parameters, sharing one architecture and tokenizer, are each trained once on FineWeb-Edu to a stable-phase checkpoint, then branched into an identical 800M-token linear-decay phase in which 600M tokens are fresh web text (C1), human Q&A text (C1b), repeated base data (C0), or synthetic text from one of six Qwen2.5-Instruct teachers (1.5B to 72B) written under one frozen prompt pool, one decoding configuration and teacher-agnostic filters, at equal student-tokenizer tokens. Outcomes are chance-corrected accuracy over a floor-gated benchmark set and held-out NLL on human-written instruction text, with [r] seeds per cell and pre-registered tests.
