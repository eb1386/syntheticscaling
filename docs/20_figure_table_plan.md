## 0. Conventions (binding for every figure)

1. **Error bars** are 95% confidence intervals across seeds (t-based, df = r − 1 per cell, or the pooled within-S df where the plan says so), and every panel prints r for the cells it shows. Item-only intervals are never drawn as the primary bar; where a paired-item bootstrap CI is added it is drawn as a second, thinner cap and labelled. Bars are never standard errors without saying so (doc 12 §8.2).
2. **Fitted curves** (F1 quadratic, F2 saturating, M4, data-scaling form) carry a percentile bootstrap band (B = 2,000 for T* fits, B = 5,000 for STE and T$), labelled "bootstrap 95%".
3. **Individual seed points** are overlaid on every cell mean (small, jittered on x), so that r and the spread are visible.
4. **Axes**: teacher size on log₂ scale with tick labels at the actual sizes (0.5B, 1.5B, 3B, 7B, 14B, 32B, 72B); the 0.5B rung is drawn with an open marker and excluded from primary fits; student size on log₂ scale with a secondary axis in N_ne; P_cc in chance-corrected points; NLL in nats per token in the student tokenizer (lower is better; axis is not inverted, the caption says so); cost in the unit named in the panel title.
5. **Reference bands**: C0, C1 and C1b are horizontal bands (mean ± 95% CI) in every transfer-curve panel; C1 is the primary comparator and is drawn darkest.
6. **Colour and marker**: one colour per student size (fixed across all figures), one marker per teacher size (fixed), the cross-family anchor as a distinct hollow marker, censored estimates as arrows. Colourmaps for heatmaps are diverging and centred at 0 for gains.
7. **Placement**: main text holds F1 to F10 and T1 to T15; everything else is appendix. Any figure may be moved to the appendix at layout time, never the reverse without re-checking the caption vocabulary of doc 12 §8.3.
8. **Captions** state: outcome, comparator, r, CI type, δ where saturation is mentioned, and which seeds (tier 1 or tier 2) the panel uses. Captions never contain the words "law" or "optimal" unless the doc 12 §5.3 conditions are met.
9. **Placeholders**: until the runs exist every number in a caption is written as [placeholder]; figures are generated from a synthetic index (`tests/fixtures/index_synthetic.parquet`) to test the code path, and those renders are watermarked "SYNTHETIC FIXTURE".
